# 시즌 방 꾸미기 웹 서비스 - 기획 정리

> 크리스마스 트리로 시작해, 시즌마다 테마가 바뀌는 방 꾸미기 웹 서비스.
> 회원가입 없는 게스트 기반 협업 꾸미기 서비스.

## 1. 서비스 형태
- 앱이 아닌 **웹 서비스**로 우선 개발 (앱은 추후 검토)
- **회원가입 없이 게스트 기반**으로 운영 — "가볍게 즐기는" 서비스 컨셉 유지

## 2. 방(Room) 시스템
- 방 생성 시 **참여 코드**가 발급되며, 코드 공유 또는 **공유 링크**로 입장 가능
- **공개방 / 비공개방** 설정 가능
  - 공개방은 "다른 사용자의 공개된 방 접속하기" 버튼으로 랜덤 입장 가능
- **방 생성자 재입장 방식**
  - 방 생성 시 그 방의 **고유 ID**를 생성자 화면에 레이어팝업으로 최초 1회 안내
  - 이후 그 ID로 접속하는 사람을 생성자로 인식해 재입장 지원
  - ⚠️ 참여 코드/공유 링크와 방 ID는 **서로 다른 값으로 분리**해야 함 (참여자가 방 ID를 알게 되어 생성자 권한을 얻는 상황 방지)
- 방 개설자가 나가면 해당 방은 **영구 삭제**

## 3. 방 꾸미기 (핵심 인터랙션)
- 중앙의 시즌 오브젝트(트리 등)에 기본 제공 아티팩트를 **드래그 앤 드롭**으로 부착
- 아티팩트 부착 시 **간단한 메모** 남기기 가능
- 삭제 권한
  - 본인이 붙인 아티팩트: 본인이 삭제 가능
  - 방 주인: 다른 사람이 붙인 아티팩트도 삭제 가능
- **오브젝트 배치는 슬롯(격자) 방식**으로 제한 (자유배치 아님)
  - 슬롯 개수는 시즌 오브젝트마다 다르게 설정 (예: 트리 vs 벚꽃나무 vs 해변가)
  - **시즌별 최소 슬롯 수는 10개로 통일**

## 4. 시즌 테마 확장
- 크리스마스 트리로 시작 → 이후 계절/특별한 날에 맞춰 오브젝트 교체
  - 봄: 벚꽃나무
  - 여름: 해변가
  - 가을: 단풍나무
  - 겨울: 크리스마스 트리
- 특별한 날(발렌타인, 할로윈 등) 테마도 추후 추가 검토

## 5. 지난 시즌 방 둘러보기
- 모든 슬롯이 채워진(완성된) 방들 중 **랜덤으로 노출**, 오브젝트 등록 불가(열람 전용)
- 완성된 방이 10개 미만이면 **미완성 방도 함께 노출**
- 조건을 만족하는 방이 하나도 없으면 **"지난 시즌에 완성된 (시즌에 맞게) 방이 없어요"** 문구 표시
- ❓ 미결정: 현재 시즌 진행 중에도 지난 시즌 목록을 볼 수 있는지, 아니면 시즌이 끝나야 "지난 시즌"에 편입되는지

## 6. 실시간 동기화
- **1차: 폴링 방식**으로 시작
- 이용자 증가 시 **웹소켓**으로 전환

## 7. 자동 삭제 정책
- 방 생성 후 **30일 경과** + 설치된 오브젝트 **5개 미만**이면 자동 삭제
- 저장소 관리 및 의미 없는 방 최소화 목적
- (시즌별 최소 슬롯 10개 보장 기준과 연동되는 절대 개수 기준)

## 8. 어뷰징 방지 / 모더레이션
- 방 생성 횟수를 **IP 또는 세션 기준으로 제한**
- 신고 기능 + 금칙어 필터 도입 검토
- 신고가 누적되면 **우선 비활성방으로 전환** → 관리자가 유지/삭제 여부 판단
- 개인정보(IP 등) 처리는 최소 수집 원칙 준수 필요 (신고/차단 목적 외 미사용, 개인정보처리방침 고지 필요) — 실제 적용 전 법률 전문가 상담 권장

## 9. 완성 결과 공유
- 완성된 방을 이미지 등으로 **공유하는 기능** 추가 예정
- 공유 시 **메모 내용 포함 여부를 선택**할 수 있도록 함 (타인의 개인정보 노출 방지 목적)

## 10. 모바일 대응
- 드래그 앤 드롭이 핵심 인터랙션이므로 **터치 이벤트 대응 필수**로 인지하고 있음

아래 프롬프트를 Claude Design에 전달해 목업/프로토타입 제작 예정. 우선순위는

톤앤매너 위주로 러프하게 요청.

시즌마다 테마가 바뀌는 "방 꾸미기" 웹 서비스의 UI/UX 디자인을 만들어줘.

## 서비스 컨셉
크리스마스 시즌에는 트리를, 봄에는 벚꽃나무를, 여름에는 해변가를, 가을에는 단풍나무를 
꾸미는 감성적인 협업 웹 서비스야. 회원가입 없이 누구나 가볍게 참여할 수 있는 게스트 
기반 서비스이고, 여러 명이 하나의 방에 모여 함께 오브젝트를 꾸미는 게 핵심이야.

## 핵심 화면 구성
1. **메인/랜딩 페이지**
   - 현재 시즌 테마(예: 크리스마스) 소개
   - "방 만들기" / "코드로 입장하기" / "랜덤 공개방 입장하기" 버튼
   - "지난 시즌 방 둘러보기" 메뉴 진입점

2. **방 생성 직후 안내 팝업(레이어팝업)**
   - 방의 고유 ID(생성자 전용, 재입장용)를 강조해서 보여주는 화면
   - "이 코드를 잃어버리면 다시 내 방에 못 들어올 수 있어요" 같은 안내 문구 포함
   - 참여자에게 공유할 참여 코드/링크는 별도로 안내 (방 ID와 시각적으로 구분되게)

3. **방 메인 화면 (꾸미기 화면)**
   - 화면 중앙에 시즌 오브젝트(트리 등)가 크게 배치, 오브젝트에는 슬롯(격자)이 있고 
     슬롯마다 아티팩트를 붙일 수 있음
   - 하단 또는 사이드에 드래그 가능한 기본 아티팩트 목록(장식 아이콘들)
   - 아티팩트를 슬롯에 드래그하면 짧은 메모를 입력하는 말풍선/팝업이 뜸
   - 이미 붙은 아티팩트에 마우스오버/터치하면 남긴 메모가 보이고, 삭제 버튼(본인 것만, 
     방장은 전체) 노출
   - 공개방/비공개방 여부, 참여 코드 공유 버튼이 상단에 위치
   - 모바일 터치 환경에서도 자연스러운 드래그 앤 드롭 고려

4. **지난 시즌 방 둘러보기**
   - 완성된(슬롯이 가득 찬) 지난 시즌 방들을 갤러리 형태로 랜덤 노출
   - 열람만 가능하고 오브젝트 추가는 불가능하다는 걸 시각적으로 명확히 표현 (예: 
     "읽기 전용" 배지)
   - 조건에 맞는 방이 없을 경우의 빈 상태(empty state) 화면도 함께 디자인

5. **완성 결과 공유 화면**
   - 완성된 방을 캡처/공유하는 화면
   - 메모 내용 포함 여부를 선택할 수 있는 토글

## 톤 & 무드
- 따뜻하고 아기자기한 느낌, 손으로 꾸민 듯한 정감 있는 일러스트 스타일
- 시즌에 따라 색감이 확 바뀌는 걸 강조 (겨울: 화이트/레드/그린, 봄: 파스텔 핑크, 
  여름: 블루/옐로우, 가을: 오렌지/브라운)
- 회원가입 없는 가벼운 서비스인 만큼 복잡한 UI보다는 직관적이고 심플한 인터랙션 위주로

## 우선순위
방 메인 화면(꾸미기 화면)과 방 생성 직후 안내 팝업을 가장 먼저, 자세하게 디자인해줘. 
나머지 화면은 톤앤매너를 맞춘 수준으로 러프하게 스케치해도 괜찮아.
