# 05. 프로토타입 안내

## 파일
| 파일 | 스타일 | 내용 |
|---|---|---|
| `prototype/pixel-3trees.html` | 픽셀아트 | **기준 버전.** 나무 3그루, 층별 구역 랜덤 슬롯, 나무별 조명 선택 |
| `prototype/flat-1tree.html` | 플랫 일러스트 | 추후 검토용 보관. 나무 1그루, 고정 슬롯 12칸 (3그루/랜덤 슬롯 미적용) |

둘 다 **단일 HTML 파일**이며 외부 의존성은 Google Fonts뿐입니다. SVG 에셋은 JSON으로 HTML 안에 들어 있습니다(`const A = {...}`). 저장은 브라우저 localStorage만 사용하므로 **다른 기기/사람과 공유되지 않습니다.**

## 구현된 것 (실제 서비스로 옮길 대상)
- **방 생성 직후 안내 팝업**: 방장 전용 ID(빨간 테두리, 분실 경고)와 참여 코드(공유용)를 시각적으로 구분. "ID를 저장했어요"를 눌러야 닫힘(바깥 클릭/ESC로 닫히지 않음). 상단 "내 방 ID" 버튼으로 다시 열기
- **상단 바**: 방 이름, 공개/비공개 배지(방장만 전환), 전체 진행률(채운 칸/전체 칸), 조명 꾸미기·내 방 ID(방장만), 참여 코드 복사
- **장식 달기**
  - 드래그: Pointer Events로 마우스/터치 통합. 8px 이상 움직여야 드래그 시작, 포인터에서 가장 가까운 허용 슬롯을 하이라이트해서 스냅
  - 모바일 가로 스크롤 목록에서는 **가로로 미는 동작은 스크롤**, 위로 끌면 드래그 (`touch-action: pan-x` + 방향 판정)
  - 탭 선택: 장식을 눌러 고른 뒤 빈 슬롯을 누름 (키보드 Enter/Space도 동일)
  - 드래그/선택 중에는 허용 슬롯만 강조, 나머지는 흐리게
  - 놓으면 메모 입력 팝업(40자, Enter로 확정, 한글 조합 중 Enter 무시 `isComposing`)
- **장식 보기**: 마우스 올리면 메모 말풍선, 누르면 상세 팝업(작성자, 메모, 삭제 버튼). 삭제 버튼은 본인 장식이면 "장식 떼기", 방장이 남의 장식을 볼 때 "방장 권한으로 떼기"
- **조명 꾸미기**(방장): 나무 탭 → 2~4층별로 5개 옵션(없음 + 조명 4종)
- **완성 표시**: 나무별 이름표가 "완성"으로, 전체가 다 차면 상단 배너
- **접근성**: 슬롯/장식은 모두 `<button>`과 `aria-label`, 팝업은 `role="dialog"` + 포커스 이동/복귀, ESC로 닫기/선택 취소, `prefers-reduced-motion` 대응
- **테마**: 라이트/다크 모두 CSS 변수 토큰으로 정의

## 프로토타입에 없는 것 (새로 만들 것)
- **방 삭제**(방장 전용): 상단 바 또는 방 정보 메뉴에 "방 삭제" 버튼 → 되돌릴 수 없다는 경고 + 확인 입력 → 삭제 후 메인으로 이동. 참여자 화면에는 "방장이 방을 삭제했어요" 안내
- **방장 재입장 입력 화면**: 메인에서 방장 키를 입력해 내 방으로 들어가기

## 테스트용 기능 (실제 서비스에 넣지 말 것)
하단 어두운 띠 "프로토타입 설정":
- 방장으로 보기 / 참여자(민지)로 보기 전환 — 권한 확인용
- 반짝임 켜기/끄기 — 실제 서비스에서는 사용자 설정으로 남겨도 됨 (사용자에게 확인)
- 층 구역 보기 — 슬롯 생성 디버그용 오버레이
- 장식 자리 다시 뽑기 / 처음 상태로 되돌리기
- 다른 참여자("하늘", "도윤")가 단 것처럼 보이는 **데모 장식** 4개

## 옮길 때 기준
- 프로토타입 JS는 한 파일에 전부 있으므로 **모듈로 분리**: 에셋/테마 설정, 슬롯 생성(공용), 상태 저장소, 트리 렌더러, 드래그 컨트롤러, 팝업들
- `localStorage` 저장(`save()`) 부분을 **웹소켓 메시지 전송**으로, 로컬 상태 변경을 **서버 이벤트 수신 후 반영**으로 바꾸기 (낙관적 반영을 하면 `SLOT_TAKEN` 오류 시 되돌리기 필요)
- 권한 판정 `canDelete`, 슬롯 허용 `accepts`는 **공용 모듈**로 만들어 서버와 클라이언트가 같은 코드를 쓰되, 최종 판단은 서버
- SVG는 빌드 시 문자열로 가져와 인라인 삽입 (애니메이션 때문). 에셋의 원본 파일에는 C2PA 메타데이터가 들어 있어 용량의 대부분을 차지했으므로, 여기 `assets/` 폴더의 파일은 **메타데이터를 제거한 버전**입니다
- 렌더링은 방 전체를 `innerHTML`로 다시 그리는 단순 방식입니다. 실시간 이벤트가 잦아지면 **바뀐 슬롯만 갱신**하도록 바꾸세요
